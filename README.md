# Análisis de planes tarifarios en telecomunicaciones
Analizar la rentabilidad de planes tarifarios y el comportamiento de los clientes 
a partir de su consumo real de servicios de telecomunicaciones.

Este proyecto analiza el comportamiento de clientes y la rentabilidad de planes tarifarios
en una empresa de telecomunicaciones, utilizando datos de consumo real de llamadas,
mensajes y datos móviles.

El objetivo es identificar qué planes generan mayores ingresos, cómo se comportan los
usuarios y qué variables influyen directamente en la facturación mensual.

## Preguntas de negocio
- ¿Qué plan tarifario es más rentable?
- ¿El consumo real de los clientes coincide con lo que incluye su plan?
- ¿Existen diferencias significativas en ingresos entre planes?
- ¿Qué tipo de usuario genera mayor ARPU?

## Herramientas utilizadas
- Python (Pandas, NumPy)
- Visualización: Matplotlib, Seaborn
- Análisis estadístico
- Jupyter Notebook
